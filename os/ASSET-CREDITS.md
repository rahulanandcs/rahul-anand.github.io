# Desktop assets

## Windows 7 landscape

`landscape.jpg` is a photograph of Maidi Lake by **appealdahal**, downloaded
at 2048 × 1536 from the WordPress Photo Directory.

- Source: https://wordpress.org/photos/photo/3676983f4b/
- License: CC0, https://creativecommons.org/publicdomain/zero/1.0/
- Download: https://pd.w.org/2026/02/3676983f4bd68e401.62592129-2048x1536.jpg

The photograph is used unmodified. CSS controls its crop and adds a subtle
dark overlay to keep white desktop text readable.

## Icons and Studio Glass wallpaper

The eight classic app icons are authored SVG in `icon()` in `os.js`.
The glass icons use the same existing semantic line symbols with dimensional
blue surfaces. No Microsoft or Apple icon files are included.

The Studio Glass wallpaper consists of CSS curves and gradients in `desktop.css`.
The supplied purple desktop reference informed its materials and layering;
the implementation uses blue-gray, logo green, and royal blue.

Project logos, portraits, and project media remain the user's existing assets.
